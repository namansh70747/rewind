# Rewind

A local flight recorder and counterfactual debugger for Python AI agents.

**Status: working local alpha, 0.1.0.** Run `fr demo` to generate a complete offline
investigation with failed, passing and safely forked runs. See the repository README
for installation and actual capture coverage.

- [Demo and viva guide](demo-guide.md)
- [Implemented architecture](implementation.md)
- [Validation evidence](validation.md)
- [Original research roadmap](roadmap.md)

The historical design documents define research targets, not present guarantees.
See the [26-week evidence ledger](roadmap-status.md) for implemented features and
remaining real-data, qualification and release gates. Optional fleet, MCP, LangGraph
and trace workflows are available in the local candidate.
